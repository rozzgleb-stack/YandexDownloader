# \# Yandex Downloader 32

# 

# \*\*Made by glebasya32\*\*

# 

# Удобное приложение для Windows, позволяющее скачивать фотографии и видео из публичных папок Яндекс Диска.

# 

# \### Возможности

# \- Скачивание фотографий и видео

# \- Одновременная загрузка нескольких файлов

# \- Регулировка количества загрузок

# \- Отображение скорости и оставшегося времени

# \- Поддержка русского, английского, белорусского и китайского языков

# \- Звуковое уведомление о завершении

# \- Светлый интерфейс с объёмными кнопками
