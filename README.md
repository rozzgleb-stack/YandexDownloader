## 📌 О программе

**Yandex Downloader 32** — приложение для Windows, позволяющее скачивать фотографии и видео из публичных папок Яндекс Диска. Вставьте ссылку на папку, выберите место сохранения и начните загрузку.

## ✨ Возможности

| Функция | Описание |
| --- | --- |
| 📁 Загрузка папок | Скачивание фотографий и видео из публичных папок |
| ⚡ Параллельная загрузка | Одновременное скачивание нескольких файлов |
| 🎛️ Управление нагрузкой | Настройка количества одновременных загрузок |
| 📊 Статистика | Скорость, прогресс и примерное оставшееся время |
| 🌍 Четыре языка | Русский, English, Беларуская, 中文 |
| 🔔 Уведомления | Отключаемый звук по завершении загрузки |
| 🖥️ Интерфейс | Светлая тема и объёмные кнопки |

## 🚀 Установка

1. Откройте **[Releases](https://github.com/rozzgleb-stack/YandexDownloader/releases/tag/v6.4.0)**.
2. Скачайте сборку Windows из раздела **Assets**.
3. Если это архив, распакуйте его.
4. Запустите `.exe`-файл приложения.

> Для готовой Windows-сборки не требуется отдельная установка Python.

## 💡 Как пользоваться

1. Откройте публичную папку Яндекс Диска и скопируйте её ссылку.
2. Вставьте ссылку в приложение с помощью **Ctrl+V**.
3. Выберите папку сохранения.
4. Настройте количество параллельных загрузок.
5. Запустите скачивание и следите за прогрессом.

> **Важно:** приложение предназначено для публичных ссылок на папки, а не для отдельных файлов или закрытых папок.
